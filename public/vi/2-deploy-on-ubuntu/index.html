2.1. Cài đặt hệ cơ sở dữ liệu MySQL

  • Bước 1. Chạy câu lệnh sau để cài đặt ứng dụng MySQL Server.
sudo apt update
sudo apt install -y mysql-server
  • Bước 2. Đổi mật khẩu cho người dùng root.

    • Bước 2.1. Chạy câu lệnh sau để kích hoạt MySQL CLI.

      sudo mysql

    • Bước 2.2. Thay đổi ‘Mật khẩu đủ mạnh’ thành mật khẩu của bạn, và chạy câu lệnh SQL sau.

      ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'Mật khẩu phức tạp';
FLUSH PRIVILEGES;

      !!! Ghi chú lại mật khẩu để dùng ở các bước sau.

    • Bước 2.3. Chạy câu lệnh sau để thoát khỏi MySQL CLI

      exit

2.2. Cài đặt Java Runtime Environment

Chạy câu lệnh sau để cài đặt JRE.

sudo apt install -y openjdk-8-jre-headless

2.3. Triển khai ứng dụng ShareNote

2.3.1 Tạo database cho ứng dụng ShareNote

  • Bước 1. Chạy câu lệnh sau để kích hoạt MySQL CLI.
mysql -u root -p

  • Bước 2. Sau đó nhập mật khẩu của người dùng root ở Phần 2.1 - Bước 2.2.

  • Bước 3. Chạy câu lệnh sau để tạo database cho ứng dụng ShareNote.

CREATE DATABASE NoteDB;

  • Bước 4. Chạy câu lệnh sau để thoát khỏi MySQL CLI
exit

2.3.2. Chuẩn bị các biến môi trường cho ứng dụng ShareNote

Thay thế nội dung “Mật khẩu của người dùng root ở bước 2.2.”. Sau đó chạy các câu lệnh sau để thiết lập các biến môi trường cho ứng dụng ShareNote.

export MYSQL_HOST=localhost
export MYSQL_DATABASE=NoteDB
export MYSQL_USER=root
export MYSQL_PASSWORD=Mật khẩu của người dùng root ở bước 2.2.

2.3.3. Chạy ứng dụng ShareNote

  • Bước 1. Chạy câu lệnh sau để tải xuống ứng dụng ShareNote.
wget "https://example-corp-storage.s3.amazonaws.com/deploy-artifact/demo-0.0.1-SNAPSHOT.jar" -O demo-0.0.1-SNAPSHOT.jar
  • Bước 2. Chạy câu lệnh sau để khởi chạy ứng dụng ShareNote. Ứng dụng sẽ chạy ở trong nền, nên ta có thể tắt session SSH hoặc terminal mà không làm ngắt ứng dụng.
java -jar demo-0.0.1-SNAPSHOT.jar &

  • Bước 3. Kiểm tra xem ứng dụng ShareNote có đang chạy đúng không bằng cách truy cập vào http://localhost:8080/ bằng trình duyệt (lưu ý port 8080).
    Hoặc có thể kiểm tra bằng lệnh wget:
wget localhost:8080
